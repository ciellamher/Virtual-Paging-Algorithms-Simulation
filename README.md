**algorithmic-memory-allocation-simulator**
A modern, interactive Streamlit desktop application visualizing classic Operating System memory management and page replacement algorithms, supercharged with AI insights.

### 01 — INSTALL

Bash
> git clone https://github.com/ciellamher/algorithmic-memory-allocation-simulator.git
> cd algorithmic-memory-allocation-simulator
> pip install streamlit pandas

---

### 02 — USE

> streamlit run app.py

The visualization dashboard will automatically open in your default browser.

---

### 03 — WHAT'S INSIDE

- `app.py` — The main Streamlit dashboard and UI logic.
- `algorithms.py` — Core logic tracking page hits, faults, and replacements.
- `ai_insights.py` — Integration module for Gemini-powered contextual explanations.
